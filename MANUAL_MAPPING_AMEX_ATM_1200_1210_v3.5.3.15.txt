AMEX ATM 1200/1210 · MANUAL MAPPING v3.5.3.15

Network Specifications - Authorization · October 2023
- ATM Financial Transaction Request (1200): Chapter 5, p. 5-91 onward.
- ATM Financial Transaction Response (1210): Chapter 5, p. 5-105 onward.
- 1200 mandatory profile used:
  Bit 3 Processing Code
  Bit 4 Amount
  Bit 11 STAN
  Bit 12 Local Date/Time
  Bit 19 Acquirer Country
  Bit 22 POS Data Code AN(12)
  Bit 24 Function Code = 200
  Bit 26 MCC = 6011
  Bit 32 AIN
  Bit 35 Track 2
  Bit 37 ARN
  Bit 41 Terminal ID
  Bit 43 ATM Name/Location
  Bit 49 Transaction Currency
  Bit 52 PIN
  Bit 55 ICC Data conditional
- 1210:
  Bit 31 TID generated by Network
  Bit 38 Approval Code
  Bit 39 Action Code N(3)
  Bit 33 Forwarding Institution ID required 1118000000511
  Bit 50 Reconciliation Currency

Codes Reference Guide · October 2023
- 014000 Cash Request / Cash from Network/Franchise ATM.
- 014008 Cash Disbursement Debit.
- Action Code 000 Approved.
- Action Code 100 Deny.
- Action Code 116 Not sufficient funds.

TID lifecycle
The Network creates the TID for the 1200 and a certified Acquirer receives it in the 1210.
