VISA — Full Service POS Online Messages – Technical Specifications (edición 15 oct 2025; los atributos coinciden con la del 14 abr 2025)
  Field 22  POS Entry Mode Code ............ 4 N: pos. 1-2 modo (01, 02, 05, 07, 10, 90, 91, 95), pos. 3 capacidad de PIN (0, 1, 2, 8), pos. 4 relleno 0.
            No se devuelve en respuestas. "Visa Transactions: si el Field 52 está presente, el Field 22 no puede ser 01 ni 10".
            Valores usados: POS chip 0510, contactless 0710, banda 0210, manual 0110, QR 0100; Wallet 0710; E-Commerce 0120
            (01 = ingreso manual, 2 = terminal que no puede enviar PIN online; el manual no define un código específico de e-commerce).
  Field 42  Card Acceptor Identification Code .. 15 ANS fijo. Mastercard DE 42 = ans-15.
  Field 55  ICC-Related Data, Usage 1 ......... 1 byte de longitud + Dataset ID 01 (1 byte) + longitud del dataset (2 bytes) + TLV.
            Mastercard DE 55 (Customer Interface Specification) = TLV sin dataset.

AMERICAN EXPRESS — Network Specifications – Financial/Non-Financial (oct 2023), capítulo 3
  POS First and Second Presentment (1240) ... 1400 bytes; campos 1 a 135 con sus posiciones. Reglas: numéricos reservados = ceros,
  alfanuméricos reservados = espacios. Campos obligatorios completados: 1, 2, 3, 4, 5, 13, 18, 20, 21, 23, 28, 29, 30, 31, 35, 36, 37,
  39, 41, 62, 63, 64, 65, 66, 68, 106, 109, 113, 114, 116.
  Function Code 200 (Codes Reference Guide: "Original financial request/advice (First Presentment)").
  Format Code 20 = General Format (Codes Reference Guide).
  File Header (9824) y File Trailer (9825) ... 1400 bytes. Header: 1-4, 112-119, 120-125, 212-222, 252-254, 1000-1005, 1032-1039
  (valor requerido 00000001), 1040-1050 (90000000002 = Global Network Services). Trailer: además 939-944 (cantidad de créditos),
  945-950 (débitos), 951-966 (total créditos), 967-982 (total débitos), 983-999 (hash total) y 1032-1039 = total de registros
  del archivo con header y trailer.
  ATM Reconciliation (Authorization spec): header, detalle y trailer de 500 bytes; header verificado (posiciones 1, 11-16, 18-27, 29-36).

VISA — Field 63 (V.I.P. Private-Use Fields) y Field 60 (Additional POS Information), edición 15 oct 2025
  Field 63  1 byte de longitud + 63.0 Bitmap (3 bytes) + subcampos presentes. 63.1 Network ID = 2 bytes BCD (0002 = Visa/Visa Electron,
            0000 = priority routing). 63.3 Message Reason Code = 2 bytes BCD. Bit 1 del byte 1 = 63.1; bit 3 = 63.3 (bitmap A00000).
            "Los adquirentes Visa deben especificar 0002; en cada mensaje posterior de la transacción debe aparecer el mismo valor."
            63.3 (reversas del adquirente): 2501 anulada por el cliente, 2502 no completada (timeout o falla del POS), 2503 sin confirmación
            del POS, 2504 reversa parcial de una autorización 0100, 2505 reversa de BASE II. No se usa en respuestas.
            Antes: el POS y el ATM enviaban solo "2501" (4 caracteres fijos, sin bitmap ni prefijo). Ahora: A00000 + 0002 + código, LLLVAR.
  Field 22  "Obligatorio en las reversas 0400 y 0420 con el mismo valor del mensaje original; no se devuelve en respuestas."
            Las reversas Visa del POS y del ATM ahora lo incluyen; las respuestas 0410/0430 no.
  Field 60  Longitud variable (hasta 6 bytes, 12 N); subcampos 60.1 tipo de terminal, 60.2 capacidad de lectura, etc. "Puede usarse en
            todas las solicitudes y advices de una transacción", sin ser obligatorio en el POS.

NO VERIFICABLE CON LOS MANUALES CARGADOS
  Mensajes 0500/0510 (cierre de lote del POS): ninguno de los PDFs de Visa ni de Mastercard define su layout, por lo que no se puede
  afirmar cuál es el uso correcto del DE60 ahí. Se corrigió lo estructural: el DE48 salía sin prefijo de longitud (argumentos invertidos
  en el código) y el DE60 era fijo; ahora ambos son LLLVAR, y el DE60 se rotula como "didáctico: número de lote".
  American Express no define mensajes 05xx: su cierre se hace con el archivo de clearing 1240. En el POS Amex el 0510 usa el Action Code
  de 3 dígitos del perfil Amex.
