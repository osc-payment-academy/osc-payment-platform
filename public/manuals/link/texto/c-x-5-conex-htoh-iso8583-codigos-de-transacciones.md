# LINK — C-X-5_Conex_HtoH_ISO8583_Códigos de Transacciones



En este capítulo se describen los códigos que usan en la conexión  HOST-TO-HOST bajo la norma ISO 8583.

Los códigos de transacciones utilizados por el sistema tienen la siguiente estructura: 'nnxxyy', donde:

- Los dos primeros caracteres (nn) indican el código de transacción propiamente 
	 dicho.

- Los dos siguientes (XX) indican el tipo de cuenta DESDE.(ver Códigos de tipos de 
	 Cuenta en el capítulo Nº X.7 del presente manual).

- Los dos últimos (YY) indican el tipo de cuenta HACIA (ver Códigos de tipos de 
  Cuenta en el capítulo Nº X.7 del presente manual).

Donde se hace referencia a Moneda Local, significa moneda del país donde se realiza la transacción
