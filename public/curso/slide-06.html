Anatomía de una trama ISO 8583

Una trama ISO 8583 siempre está formada por tres grandes componentes. El primero es el MTI, el segundo es el Bitmap y el tercero son los Data Elements. Vamos a ver qué representa cada uno. Comenzamos por el MTI, o Message Type Indicator. El MTI responde una pregunta muy sencilla: ¿Qué tipo de mensaje estoy recibiendo? En este ejemplo vemos un 0200, que representa una solicitud de autorización financiera. Si en lugar de un 0200 llegara un 0210, sabríamos que se trata de una respuesta. Si fuera un 0400, hablaríamos de una reversa. Y si fuera un 0800, sería un mensaje de administración de red. Es decir, el MTI nos dice cuál es el propósito del mensaje antes de analizar cualquier otro dato. Después aparece el Bitmap. El Bitmap es probablemente el concepto más importante de ISO 8583. Su función no es transportar información de la transacción. Su función es indicar qué campos vienen presentes dentro del mensaje. Podemos imaginarlo como un índice o una tabla de contenido. Cada bit representa un Data Element o campo Si el bit está encendido (es igual a 1), significa que ese campo viene incluido. Si está apagado (es igual a 0), ese campo simplemente no existe dentro de esa trama. Gracias al Bitmap, el parser sabe exactamente qué información debe leer y en qué orden. Finalmente encontramos los Data Elements. Aquí es donde realmente viaja la información de la transacción. Los Data Elements contienen todos los datos necesarios para autorizar una operación. Por ejemplo: el número de tarjeta; el código de procesamiento; el monto; la fecha y hora; el STAN; el identificador del terminal; el comercio; la moneda; y todos los demás datos necesarios para que el emisor pueda tomar una decisión. Es importante entender que los Data Elements no siempre son los mismos. Una autorización puede contener un conjunto de campos. Una reversa puede contener otro. Y un mensaje de administración de red puede contener un conjunto completamente distinto. Precisamente por eso existe el Bitmap. El Bitmap le indica al receptor cuáles de todos esos Data Elements vienen presentes en cada mensaje. Si tuviera que resumir ISO 8583 en una sola frase sería la siguiente: El MTI dice qué tipo de mensaje es. El Bitmap dice qué campos vienen. Los Data Elements contienen la información de la transacción. Esa es la base sobre la cual funciona absolutamente todo el estándar. A partir de las próximas láminas vamos a profundizar en cada uno de estos tres componentes por separado, comenzando por el MTI y luego por el Bitmap y los Data Elements.
