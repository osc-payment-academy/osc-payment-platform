Bitmap primario

El Bitmap en ISO 8583 actúa como el 'índice' o 'mapa' de la transacción: le dice al sistema exactamente qué campos de datos vienen en el mensaje y cuáles no." La estructura (64 bits): "Un bitmap estándar consta de 64 casilleros o posiciones, donde cada casilla corresponde a un Data Element (DE) específico del mensaje." El valor del Bit (0 o 1): "Para entender qué viaja en la transacción, solo debemos mirar el valor dentro de cada casilla: Un 0 significa que el campo está ausente (no llegó en este mensaje).* Un 1 significa que el campo está presente y contiene información."* Explicando el ejemplo visual: "En el gráfico que están viendo, las casillas destacadas en color muestran los campos activos para esta transacción: DE2 (Valor 1): Contiene el número de tarjeta (PAN).* DE3 (Valor 1): Indica el código de procesamiento.* DE4 (Valor 1): Trae el monto de la transacción.* DE7 (Valor 1): Especifica la fecha y hora de transmisión.* DE11 (Valor 1): Contiene el número de secuencia o STAN.* El resto de las 59 casillas tienen un 0, por lo que el sistema sabe que no debe buscar ni procesar esa información en esta solicitud." 💡 Cierre o Remate "En resumen: el Bitmap permite que el mensaje sea ligero y dinámico; los sistemas no necesitan adivinar la estructura, simplemente leen los 1 para procesar únicamente la información que está presente.
